## Project Summary

The Goldbus Light Controller is a desktop application designed to manage and control various lighting equipment. It provides functionalities for WLED device control, DMX fixture management, Art-Net output, USB-DMX serial output, an audio-reactive Party mode, and network/access-point configuration. The application is built as a cross-platform solution, integrating a Go backend with a React/TypeScript frontend via the Wails framework.

### Tech Stack

-   **Backend:** Go
-   **Desktop Framework:** Wails
-   **Frontend:** React, TypeScript, Vite, Tailwind CSS
