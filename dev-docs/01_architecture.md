# 🏗️ Architecture & Tech Stack

> _Generated by Gemini with google/gemini-1.5-pro on 2026-05-20._

The Goldbus Light Controller currently employs a robust architecture leveraging Go for its powerful backend logic and system interactions, coupled with a modern React/TypeScript frontend for an interactive user experience. Wails acts as the desktop application framework, seamlessly bridging the Go and React components.

## Core Technologies

-   **Backend Language:** Go
-   **Desktop Framework:** Wails v3
-   **Frontend Language:** TypeScript
-   **Frontend Framework:** React 18
-   **Frontend Tooling:** Vite, Tailwind CSS, shadcn/ui (built on Radix UI)
-   **State Management (Frontend):** Zustand
-   **3D Rendering (Frontend):** Three.js, react-three-fiber

## Dependency Management

-   **Go Modules:** For Go backend dependencies (managed via `go.mod`).
-   **npm/Yarn:** For TypeScript/React frontend dependencies (managed via `package.json` and `package-lock.json`).

## Architectural Style

The application follows a client-server architecture, typical for Wails applications:

-   **Go Backend:** Handles all the heavy lifting, including device communication (WLED, DMX), audio processing, network configuration, and persistence. It exposes an API that the Wails runtime makes available to the frontend.
-   **React Frontend:** Provides the user interface. It communicates with the Go backend through generated bindings provided by Wails, eliminating the need for manual IPC (Inter-Process Communication).
-   **Wails:** Serves as the lightweight desktop shell, embedding a Chromium webview for the React UI and providing the bridge for frontend-backend communication.

This separation of concerns allows for clear development boundaries and enables the use of best-in-class tools for both backend and frontend development.

### Future Architectural Direction (Kotlin Multiplatform)

It is important to note that there is a documented plan for migrating this application to a Kotlin Multiplatform (KMP) desktop application. This migration, detailed in `gemini-kmp.md`, aims to replace the Go/Wails/React stack with Kotlin and Compose Multiplatform, along with libraries like Koin, Voyager, KorGE, TarsosDSP, and Conveyor. This indicates a strategic shift towards a unified language and framework across the entire application stack for future development.
