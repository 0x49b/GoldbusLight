## Key Directories and Their Responsibilities

| Directory        | Responsibility                                                                                                     |
| :--------------- | :----------------------------------------------------------------------------------------------------------------- |
| `cmd/goldbuslight` | Contains the `main.go` file, the primary entry point for the Go backend application.                               |

| `internal/`      | Contains the core business logic and backend services, organized by functional area (e.g., `controller`, `dmx`).   |

| `Taskfile.yml`   | Defines common development tasks and commands for both frontend and backend operations.                            |
| `go.mod`         | Specifies the Go module path and manages backend dependencies.                                                     |
| `package.json`   | Manages frontend (Node.js/TypeScript) dependencies and defines various build and development scripts for the UI.     |
