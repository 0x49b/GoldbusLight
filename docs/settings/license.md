# License and editions

Goldbus Light Controller is available in **Free** and **Pro** editions. Your edition is shown in **Settings → General → License**.

## Free edition

No license key is required. The Free edition includes:

| Feature | Included |
|---------|----------|
| WLED discovery and device control | Yes |
| WLED global presets | Yes |
| Transport console | Yes |
| Maximum WLED devices | 8 |
| DMX | No |
| Party mode | No |
| Wi-Fi access point | No |
| Configuration backup / restore | No |

## Pro edition (annual)

Pro is licensed on an **annual** basis. A valid Pro key unlocks:

| Feature | Included |
|---------|----------|
| Everything in Free | Yes |
| WLED devices | Unlimited |
| DMX (USB, Art-Net, fixtures, live output) | Yes |
| Party mode (auto and audio-reactive) | Yes |
| Wi-Fi access point provisioning | Yes |
| Configuration backup / restore | Yes |
| DMX fixture export | Yes |

## Activating Pro

1. Open **Settings → General**.
2. Copy the **Machine ID** shown in the License card.
3. Purchase or renew Pro from Goldbus and receive a license key (`GBLC1.…`).
4. Paste the key into **Pro license key** and click **Activate**.

Activation works **offline** after the key is entered. The key is bound to the machine where you activate it.

## Renewal and grace period

Pro keys contain an expiration date (typically one year from purchase). When a key expires:

1. **Grace period (14 days):** Pro features continue to work; the app shows a renewal warning.
2. **After grace:** The app returns to the Free edition. DMX and Party output stops safely; your configuration is kept.

To renew, obtain a new annual key and activate it on the same machine.

## Deactivating a license

Click **Deactivate** in Settings → License to remove the stored key and return to the Free edition. This does not delete your lighting configuration.

## Troubleshooting

| Problem | What to try |
|---------|-------------|
| "License key is not valid for this machine" | Request a key issued for this Machine ID, or deactivate on the old host first |
| "Invalid license key" | Check for typos; ensure the full `GBLC1.…` string was copied |
| Pro features missing after renewal | Activate the new key; restart the app if the edition badge still shows Free |
| DMX / Party disabled unexpectedly | Check expiry date; renew if the grace period has ended |

For support, contact Goldbus with your Machine ID and customer reference from the License screen.
