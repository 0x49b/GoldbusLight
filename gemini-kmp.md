## 1. Executive Summary

This document serves as a complete and detailed technical blueprint for the full reimplementation of the Goldbus Light Controller. We will migrate from the current Go/Wails/React stack to a modern, desktop-first **Kotlin Multiplatform (KMP)** application targeting **macOS, Linux (including Raspberry Pi ARM64), and Windows**.

The new architecture will be built on **Compose Multiplatform** for the UI and a pure Kotlin backend, preserving the entire feature set: WLED device control, DMX fixture management, Art-Net/USB-DMX output, audio-reactive Party mode, and network/access-point configuration. We will leverage modern, best-in-class libraries from the KMP and JVM ecosystems to replace each component of the original application, removing all CGO dependencies and creating a more maintainable, type-safe, and performant codebase.

## 2. Technology Choices

This table outlines the final technology stack, synthesizing the best choices from previous plans and analysis.

| Concern | Current (Go/Wails) | KMP Replacement | Rationale |
|---|---|---|---|
| **Language** | Go (Backend), TypeScript (Frontend) | **Kotlin 2.0** | Unified, modern language for the entire stack. |
| **Desktop Shell & UI** | Wails v3 + React + shadcn/ui | **Compose Multiplatform** | Native performance with Skia, direct access to JVM libraries, no IPC bridge. |
| **Dependency Injection** | Manual | **Koin** | Essential for managing the lifecycle of controllers, services, and repositories. |
| **State Management** | Zustand + Snapshot Poll | **Kotlin Coroutines `StateFlow` + Voyager `ScreenModel`** | Eliminates polling with a reactive stream of truth from the backend; `ScreenModel` manages UI-specific state. |
| **Navigation** | React Router / Conditional | **Voyager** | Lightweight, stack-based KMP routing that allows passing complex objects natively without serialization. |
| **Audio Capture & FFT**| gen2brain/malgo (CGO) + manual FFT | **TarsosDSP** | Pure JVM audio capture, windowing, and FFT. Removes the final CGO dependency while providing robust, high-performance DSP. |
| **3D Fixture Preview** | Three.js / react-three-fiber | **KorGE Engine (Embedded)** | A full KMP 2D/3D game engine, perfect for handling 3D models, lighting, and particle effects within a Compose `SwingPanel`. |
| **Persistence** | Raw JSON files via `os` | **Jetpack DataStore (Typed)** | Thread-safe, transactional, coroutine-native storage that natively outputs to `Flow`, while preserving the human-readable JSON format. |
| **HTTP Client (WLED)** | Go `net/http` goroutine pool | **Ktor Client (CIO)** | The standard, coroutine-native KMP library for all HTTP communication. |
| **mDNS Discovery** | `grandcat/zeroconf` | **JmDNS** | The most mature and reliable pure-JVM mDNS library. |
| **UDP (Art-Net)** | Go `net.PacketConn` | **Java NIO `DatagramChannel`** | A lightweight, raw implementation is sufficient and avoids heavy dependencies. |
| **USB Serial (DMX)** | `go.bug.st/serial` (CGO) | **jSerialComm** | The gold standard for JVM serial communication; handles DMX timing perfectly without CGO. |
| **Logging** | Go `log` + file tee | **Kermit** | A modern, multiplatform-first logging framework. |
| **Distribution** | Taskfile + `wails3` CLI | **Gradle + Conveyor** | Cross-platform bundling (Windows MSI, macOS App, Linux Deb) from a single CI runner, with auto-updates built-in. |

class WLEDEngine(private val console: ConsoleBus) {
    private val client = HttpClient(CIO) {
        install(ContentNegotiation) { json(Json { isLenient = true; ignoreUnknownKeys = true }) }
        engine { requestTimeout = 8_000 }
    }
    private val scope = CoroutineScope(Dispatchers.IO + SupervisorJob())

    fun submitState(device: WLEDDevice, state: Map<String, JsonElement>) {
        scope.launch {
            runCatching {
                client.post("http://${device.address}:${device.port}/json/state") {
                    contentType(ContentType.Application.Json)
                    setBody(state)
                }
            }.onSuccess { console.publish("wled", "out", device.address, "state applied") }
             .onFailure { ex -> console.publish("wled", "error", summary = ex.message ?: "unknown") }
        }
    }
    // ...
}
```

class PartyAudioEngine(private val onFeatures: (PartyFeatures) -> Unit) {
    private var dispatcher: AudioDispatcher? = null

    fun start() {
        val format = AudioFormat(44100f, 16, 1, true, false)
        dispatcher = AudioDispatcherFactory.fromDefaultMicrophone(1024, 512)
        dispatcher?.addAudioProcessor(object : AudioProcessor {
            val fft = FFT(1024)
            override fun process(event: AudioEvent): Boolean {
                fft.forwardTransform(event.floatBuffer)
                // Port Go FFT band splitting logic here using fft.modulus()
                val features = extractBands(fft.modulus(), event.rms)
                onFeatures(features)
                return true
            }
            override fun processingFinished() {}
        })
        Thread(dispatcher, "Audio-Dispatcher").start()
    }
}
```
